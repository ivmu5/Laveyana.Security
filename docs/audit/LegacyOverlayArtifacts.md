# Historical overlay artifacts

Old root-level overlay-install instructions and snapshot manifests
(`APPLY.md`, `MANIFEST.sha256`, `B05_PATCH_README.ru.md`,
`B05_PATCH_MANIFEST.json`) were removed from the active repository tree.
They described one-off ZIP patches, not the current branch or release.
Their historical content remains in Git history. For up-to-date
installation and security status, use the root README and
`Laveyana.Security.KnownLimitations.md`.

No security finding was closed by this repository hygiene change.
