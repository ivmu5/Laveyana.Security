# Исторические overlay-файлы

Из активного корня убраны инструкции/манифесты ZIP-накладок
(`APPLY.md`, `MANIFEST.sha256`, `B05_PATCH_README.ru.md`,
`B05_PATCH_MANIFEST.json`). Они относились к разовым патчам, а не
к текущему исходному дереву и релизу. История этих файлов осталась
в Git. Текущие инструкции и статус безопасности см. в основном README
и `Laveyana.Security.KnownLimitations.ru.md`.

Эта очистка сама по себе не закрывает security-находки.
